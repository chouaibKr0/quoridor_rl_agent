# Quoridor RL Agent – V2 Manifesto

With the goal of learning by experimentation and since this project is capable of expansion, I'll consider all existing work as **V1** and plan to expand the project into a broader game solver.

---

## Purpose of V2

- **Learning by Practice:** This includes reinforcement learning, game theory, adversarial search algorithms, and advanced problem solving.
- **Research by Experimentation & Experimental Design:** From the ability to implement various algorithms and solvers using various techniques, to designing statistical experiments on top of that driven by research questions aimed at obtaining the "best" solver for this game and discovering algorithm capabilities and limitations.

---

## What Type of Changes V2 Will Introduce

- **Restructuring & Refactoring:** Refactoring existing code for the new purpose.
- **New Modules:** Adding more modules that address new purposes where the existing code does not.

---

## Scope

V2 focuses on **Quoridor** and potentially its derived variants (such as multiplayer Quoridor, Ghost Quoridor, etc.), but for now, the primary focus remains solely on the classic game.

---

## About V1 Solver Design Methodology

In **V1**, the goal was to make an RL solver for the game while having fun and exploring advanced solving techniques as much as possible, regardless of optimality, rationality, algorithmic choices, or solution approach. This is how V1 came to be what it was.
